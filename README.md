# Calculator

Calculator is an Android application that extends a standard calculator with advanced mathematical operations and a built-in grade calculator.

## 🚀 Features
- Advanced operations (logarithms, powers, factorials, GCD, LCM, percentages)
- Grade calculator for computing final course grades
- Responsive UI (portrait & landscape)
- Input validation and edge case handling

## 🛠️ Tech Stack
- exp4j (Math expression evaluation)
- Material Design Components

## 📍 What This Project Demonstrates
- Mathematical expression parsing
- UI adaptability across orientations
- Error handling and validation
- Clean separation of logic and UI
